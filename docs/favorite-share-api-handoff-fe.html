Favorite And Share API Test Guide

Manual testing sheet for Postman based on the current backend contract.

Base URL
http://127.0.0.1:8000
Bearer token
Authorization: Bearer <access_token>

1. Toggle Favorite

POST /location/toggle-favorite
Auth
Required

Request Sample

{
  "locationCode": "LOC_ROOM_01"
}

Response Sample: Add Favorite

{
  "message": "Da them vao danh sach yeu thich.",
  "locationCode": "LOC_ROOM_01",
  "isFavorite": true
}

Response Sample: Remove Favorite

{
  "message": "Da xoa khoi danh sach yeu thich.",
  "locationCode": "LOC_ROOM_01",
  "isFavorite": false
}

Error Codes

  • 400: locationCode empty or invalid length
  • 401: missing token, invalid token, expired token
  • 404: location not found
  • 500: unexpected server error

GET /location/get-my-favorite-location

3. Get Share Link

GET /location/get-share-link?locationCode=LOC_ROOM_01
Auth
Not required

Request Sample

GET /location/get-share-link?locationCode=LOC_ROOM_01

Response Sample

{
  "message": "Tao link chia se thanh cong.",
  "locationCode": "LOC_ROOM_01",
  "shareUrl": "http://localhost:3001/room-detail?locationCode=LOC_ROOM_01"
}

Error Codes

  • 400: locationCode empty or invalid length
  • 404: location not found
  • 500: unexpected server error

4. Suggested Postman Flow

  1. Call POST /auth/signin to get access_token.
  2. Call POST /location/toggle-favorite with Bearer token.
  3. Call GET /location/get-my-favorite-location with Bearer token.
  4. Call GET /location/get-share-link?locationCode=LOC_ROOM_01 without token.
